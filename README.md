# SkyNet Weather App

A modern and responsive Weather Web Application built using **HTML, CSS, and JavaScript**. This app provides real-time weather updates, hourly forecasts, and a 5-day forecast using live API data.

---

## Features

* Search city with auto-suggestions
* Get weather using current location (GPS)
* Real-time weather data (temperature, humidity, wind, pressure)
* Hourly weather forecast
* 5-day forecast
* Recently searched cities (LocalStorage)
* Modern UI with glassmorphism & animations
* Fully responsive design

---

## Tech Stack

* HTML5
* CSS3 (Glassmorphism, Flexbox, Grid)
* JavaScript (ES6+)
* OpenWeatherMap API

---

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/pbhumika198/SkyNet-Weather.git
   ```

2. Navigate to project:

   ```bash
   cd skynet-weather-app
   ```

3. Open `index.html` in browser


## API Used

* OpenWeatherMap API
